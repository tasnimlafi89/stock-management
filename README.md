\# Stock Management



Full-stack stock management system for Tunisian associations — a Next.js web app and an Expo/React Native mobile app sharing the same backend.



\## Structure

\- `gestion/` — Next.js 16 web app (Clerk auth, Prisma + SQLite, daisyUI)

\- `mobile/` — Expo app (Clerk native auth, calls gestion's REST API)
